## Notes on Catalogues

### Catalogues with minimum space velocities (v_min_catalogs)

#### What
- These catalogues host minimum space velocity columns, including 3D space velocities and peculiar velocities.

#### Where
- Catalogues in config.RESULTS_CATALOGUE_DIR / "v_min_catalogs".

#### How
- Generated by running the calc_vmin.py script in computation/. The input catalogue has all the astrometric columns required to get the space velocities computed. Given a survey name, e.g., 'csc', the input catalogue is root/results/csc/catalogues/nway_match/csc_gaia_nway_match_stars_only_for_vpec.csv.

#### What's New
- Update (March 15 2025): The computation now uses the distances estimated by Bailer-Jones et al. 2022 for Gaia eDR3.

### High-velocity Source Catalogues (high-v_sources/)
#### What
- Catalogues selected from the combined master catalogues based on space velocity and/or X-ray/optical ratios.

#### Where
- In config.RESULTS_CATALOGUE_DIR / "high-v_sources"

#### How
- File names contains velocity limit and method used for selection. The method could be either "med" or "lolim", meaning that sources with median/lower-limit (1-sigma) velocity >= the given limit are selected. The "_unique" in file names means that duplicated matches have been removed from the catalogue, keeping only the closest neighbours.

- File names are also suffixed by processing stages, whose meaning are as follow:
    - stage 0: Selected only based on vpec_min_lo or vpec_min_med (catalog.combine_catalog)

    - stage 1: Stage 0 with SIMBAD types and IDs (cross-matching done with TOPCAT)

    - stage 2: Stage 1 selected for high fx/fg-ratio sources (catalog.select.selection_routines.select_high_fx_fg_ratio_sources()).

    - stage 3: Stage 2 cleaned for SIMBAD types (catalog.select.clean_simbad_types; removed unrelated types and known XRBs and pulsars).

    - stage 4: Stage 3 with cluster membership information (catalog.select.clean_cluster_members.cross_match_ids(); joined with the Hunt+23 catalogue).

    - stage 5: Stage 4 with cluster members removed. (catalog.select.clean_cluster_members.cross_match_ids())

    - stage 6: Stage 5 with extinction-corrected Gaia magnitudes. (computation.extinction_correction)

    - stage 7: Stage 6 with gspphot columns used for calibrating mh_gspphot (from the Gaia Archive).

    - stage 8: Stage 7 with Galactocentric coordinates (in catalog.manipulate.add_columns.add_cartesian_coordirnates()).

    - stage 8a: Stage 8 with likely halo sources removed, using the Viswanathan+23 halo source catalogue.

    - stage 9: Stage 8 with LMC and SMC members removed (in catalog.select.clean_smc_and_lmc).

#### What's New
- The archived catalogues have not been removed and are kept in high-v_sources_old/.
